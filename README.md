# Heartie Pal（双心宝）

## 项目介绍

双心宝（双心智能助手）聚焦心血管疾病合并心理问题的临床场景，面向患者与医生提供 24×7 的专业心理支持与智能服务。项目目标是通过权威知识与可控技术，提升患者治疗依从性与生活质量，同时为心血管医生赋能心理专业能力，减少“逛医”与医疗资源浪费。

- 市场需求：双心患者诊疗率低、反复就医的痛点普遍存在，患者、医生与医疗体系均亟需改善。
- 技术可控：基于当下成熟的大模型与 RAG 技术，可实现科普内容输出、基础心理疏导与实时问答；开发周期可控，无需复杂技术突破。
- 公益属性：不采集患者隐私数据，定位为公益与低门槛服务，更易获得信任与临床机构支持。
- 团队适配：依托技术与医疗专业背景，快速搭建“医疗+心理”的知识体系与产品原型。
- 质量保障：以 ESC、AHA 等权威指南为数据源，医学专家参与审核，并基于用户反馈持续优化。

## 首期目标（Alpha 阶段）

1. 基于 FastGPT 与 Gewechat 框架构建 RAG 能力，上线微信服务助手，覆盖 `Web 端 / 小程序端 / 公众号 AI 助手 / 微信群机器人` 场景。
2. 完成双心知识库的构建与开源，确保来源权威、结构清晰、便于社区复用与共建。
3. 在应用上线后制定后续迭代与开发计划，包含功能扩展、性能优化与临床应用验证路径。

## 项目进度规划

- 第一阶段：基础建设（2025 年 12 月）
  - 完成基础 RAG 系统搭建与双心知识库预处理
  - 实现基本对话功能并开展内部测试与功能验证
- 第二阶段：完善优化（2026 年 1 月）
  - Beta 版本上线；功能与性能优化、UI 打磨、医生培训与运营规范
- 第三阶段：试运行（2026 年 2 月）
  - 小规模测试并上线服务；邀请种子用户、收集反馈、建立用户社区与支持体系、制定推广策略
- 第四阶段：正式运营（2026 年 3 月及以后）
  - 持续迭代与优化；扩大用户规模；推进可持续发展规划
